## 📣 Suivre les nouveautés

Chaque version est publiée dans l'onglet **[Releases](../../releases)**, rédigée en cinq langues : français, anglais, allemand, espagnol et italien.

Activez **Watch → Custom → Releases** pour être prévenu de chaque nouvelle version.

## 🗺️ Voir ce qui arrive

Les évolutions prévues sont dans l'onglet **[Issues](../../issues)**, sous l'étiquette `Planned`. Vous y voyez ce qui est en cours et ce qui vient ensuite.

## 💬 Échanger avec la communauté

Une question, une idée, un retour d'expérience ? Rendez-vous dans les **[Discussions](../../discussions)**.

| Vous voulez… | Où aller |
|---|---|
| Savoir ce qui change | [Releases](../../releases) |
| Voir la feuille de route | [Issues](../../issues) · `Planned` |
| Poser une question, proposer une idée | [Discussions](../../discussions) |
| Signaler un problème dans l'app | Le formulaire d'aide intégré à l'app |

## 🔒 Un problème dans l'app ?

Utilisez **Profil → Signaler un problème ou une idée** dans l'app. Le formulaire nous transmet le contexte nécessaire (version, appareil) sans que vous ayez à publier la moindre donnée de votre activité.
