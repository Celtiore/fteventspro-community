# FTEvents Pro — nouveautés et communauté

FTEvents Pro est l'app de gestion des food trucks événementiels.

- **Nouveautés** : chaque version est publiée dans l'onglet [*Releases*](../../releases), en français, anglais, allemand, espagnol et italien.
- **Feuille de route** : les évolutions prévues sont dans l'onglet [*Issues*](../../issues) (étiquette *Planned*).
- **Discussions** : posez vos questions et partagez vos idées dans l'onglet [*Discussions*](../../discussions).

Un problème dans l'app ? Utilisez le formulaire d'aide intégré à l'app : il nous transmet le contexte nécessaire sans que vous ayez à publier la moindre donnée de votre activité.

Ce dépôt ne contient aucun code : il sert uniquement à publier les nouveautés et à échanger avec la communauté.

Site : https://www.fteventspro.app
